# Vela — Telegram Dating Mini App

سورس MVP واقعی با React + NestJS + Prisma/PostgreSQL، چت Socket.IO، پرداخت Telegram Stars و ۱۱ زبان. نام و طراحی مستقل از PURE است. این بسته برای اجرای محلی و استقرار شما ساخته شده؛ به دیتابیس یا Bot شما متصل نشده است.

**برای تست مستقیم در تلگرام با هاست رایگان، از `docs/render-staging.md` شروع کنید.** پیکربندی جدید `render.yaml` فرانت‌اند و بک‌اند را روی یک آدرس Render و Redis رایگان قرار می‌دهد؛ دیتابیس و تصاویر روی Supabase می‌مانند. انتشار واقعی هنوز انجام نشده است.

## شروع سریع در ویندوز / macOS / Linux

نیازمندی‌ها: **Node.js 22 یا بالاتر، npm، Docker Desktop**. برای تست محلی از دیتابیس تازه استفاده کنید، نه دیتابیس فعال محصول.

```bash
npm ci
```

فایل `.env.example` را به `.env` کپی کنید. در PowerShell:

```powershell
Copy-Item .env.example .env
```

در macOS/Linux:

```bash
cp .env.example .env
```

مقادیر پیش‌فرض برای PostgreSQL و Redis محلی هستند. سپس:

```bash
docker compose up -d
npm run db:generate
npm run db:migrate
npm run db:seed
npm run dev
```

مرورگر را روی **http://localhost:5173** باز کنید. در بخش حساب آزمایشی، `test-man-01` را انتخاب کنید. Backend روی پورت 3001 است؛ درخواست‌های رابط از طریق Vite به آن منتقل می‌شوند. Swagger در **http://localhost:3001/api/docs** در حالت توسعه در دسترس است.

کارهای پس‌زمینه در ترمینال دوم:

```bash
npm run worker
```

ورود تستی فقط در حالت Development فعال است. برای ورود واقعی باید برنامه از Telegram با `initData` معتبر باز شود. دکمه ورود بیرون تلگرام توضیح می‌دهد چرا احراز هویت واقعی ممکن نیست. خروج، Session را باطل می‌کند؛ ورود دوباره به همان حساب Telegram انجام می‌شود. بعد از منقضی‌شدن داده شروع Telegram، لازم است Mini App را ببندید و دوباره باز کنید.

## تست و ساخت

```bash
npm run typecheck
npm run lint
npm test
npm run build
```

تست‌ها بدون Docker یا Supabase و بدون اتصال شبکه اجرا می‌شوند: PostgreSQL مبتنی بر WASM/PGlite با Prisma adapter در حافظه استفاده می‌شود. هیچ داده‌ای در دیتابیس شما تغییر نمی‌کند. این تست، جای تست هم‌زمانی چند اتصال در PostgreSQL واقعی یا تست داخل Telegram را نمی‌گیرد.

## اتصال Supabase

۱. رمز دیتابیسی که در گفتگو فرستادید را تغییر دهید. هیچ نسخه‌ای از آن رمز در بسته نیست.

۲. از Connect پروژه، URL مناسب اتصال Backend را در `DATABASE_URL` قرار دهید. برای Migration، `DIRECT_URL` را با اتصال مستقیم قابل دسترس یا Session Pooler وارد کنید. Transaction Pooler برای Migration استفاده نشود. اگر اتصال مستقیم به IPv6 نیاز دارد و میزبان IPv4 است، Session Pooler را بررسی کنید.

۳. در `.env`، `SUPABASE_URL` و کلید سروری `SUPABASE_SERVICE_ROLE_KEY` را تنظیم کنید. آن را در متغیر `VITE_` یا فرانت‌اند قرار ندهید.

۴. Bucket موجود `dating-app-photos` را **Private** نگه دارید. آپلود از بک‌اند انجام می‌شود؛ نیازی به Policy عمومی آپلود نیست. تصاویر JPEG/PNG/WebP، حداکثر 5MB، پس از بررسی و تبدیل مجدد به WebP ذخیره می‌شوند.

۵. فقط روی دیتابیس آزمایشی تازه، Migration و Seed را اجرا کنید. برای Production فقط Migration و اسکریپت `scripts/init-production.ts`؛ Seed ممنوع است.

۶. عکس پروفایل واقعی تا تأیید مدیر وارد Discovery نمی‌شود. عکس‌های ساختگی تست از پیش تأیید شده‌اند. عکس ارسالی در چت فقط برای اعضای همان گفتگو نمایش داده می‌شود و دارای گزارش/بلاک است؛ سیستم خودکار تشخیص محتوای عکس فعال نیست.

## زبان‌ها

English `en`، 简体中文 `zh`، Русский `ru`، हिन्दी `hi`، اردو `ur`، فارسی `fa`، العربية `ar`، Türkçe `tr`، Español `es`، Deutsch `de`، Italiano `it`.

«پاکستانی» به اردو و «چینی» به چینی ساده‌شده تعبیر شده است. ترجمه‌ها در `apps/web/src/locales/*.json` هستند. فارسی/عربی/اردو RTL هستند. متن کاربران مثل Bio و پیام به‌صورت خودکار ترجمه نمی‌شود. بازبینی متن‌ها توسط افراد مسلط به زبان پیش از انتشار توصیه می‌شود. اسناد حقوقی پیش‌نویس‌اند و باید مدیر آن‌ها را بازنویسی و ترجمه کند.

## تحویل و محدودیت‌ها

- قابلیت‌های اصلی: پروفایل/تصاویر، Discovery/فیلتر، Like/Match، پیام متنی و عکس، خوانده‌شدن/تایپ، بلاک/گزارش، حذف حساب، اشتراک Stars، مدیریت کاربران/عکس/گزارش/پلن/سیاست/متن، حالت روشن/تیره.
- Swipe نامحدود است. مرد رایگان روزانه برحسب UTC می‌تواند آغازگر ۳ گفتگوی قبلاً شروع‌نشده باشد؛ پاسخ در گفتگوی موجود سهمیه مصرف نمی‌کند. سیاست Female و Other پیش‌فرض نامحدود است و در Admin قابل تغییر است.
- به‌جای JWT از Session تصادفیِ قابل ابطال در Cookie امن استفاده شده. به‌جای Turbo/pnpm از یک ریشه npm با lockfile استفاده شده تا راه‌اندازی ساده‌تر باشد. فرم‌ها با React و اعتبارسنجی مشترک Zod ساخته شده‌اند؛ کتابخانه مدیریت فرم/State اضافی لازم نشده است.
- این بسته **گواهی Production-ready یا تضمین نبود تمام باگ‌ها نیست**. گزارش واقعی اجرا در `docs/release-checklist.md` قرار دارد. AI، احراز هویت مدرکی، تشخیص خودکار پروفایل جعلی، Undo و بازپرداخت دلخواه از پنل مدیر در این نسخه نیستند.

راهنمای انتشار: `docs/deployment.md` و `docs/telegram-publishing.md`. راهنمای امنیت و محدودیت‌ها: `docs/security.md`. هیچ Secret، node_modules یا خروجی Build در ZIP تحویلی قرار نمی‌گیرد.
